# حزمة موقع شعبة IEEE IES — الجامعة الهاشمية

## شو في جوا الحزمة
| الملف | شو هو |
|---|---|
| `START_PROMPT.md` | البرومبت اللي بتنسخه وبتلصقه بـ Claude Code |
| `DESIGN_SPEC.md` | كل تفاصيل التصميم: الألوان، الخطوط، الكرت بقياساته، البطاقة التفاعلية، صفحات الموقع، بيانات الأعضاء، الـ NFC |
| `data/members.json` | بيانات الأعضاء (حاليًا إنت). كل عضو جديد = سطر جديد |
| `data/events.json` | الفعاليات (فاضي حاليًا) |
| `assets/` | اللوجوهات وصورتك (اختيارية للموقع بس) |
| `reference/card-design/` | ملفات تصميم الكرت الأصلية كمرجع |

## الخطوات
1. فك الضغط عن الحزمة بمجلد على جهازك.
2. افتح الترمينال بنفس المجلد وشغّل `claude`.
3. انسخ محتوى `START_PROMPT.md` من بعد الخط والصقه.
4. خلّيه يبني خطوة خطوة، وجرّب كل خطوة قبل ما يكمل.

## قبل ما تبرمج الكروت
- **احجز الدومين أول**، لأن الرابط بينقفل على الشريحة وما بيتغيّر.
- الرابط لكل عضو: `https://الدومين/m/الاسم` (مثلًا `/m/qusai`).
- اكتبه على الكرت بتطبيق **NFC Tools**، جرّبه على آيفون وأندرويد، وبعدين اقفله (Lock).

## ناقص
- نسخ عالية الدقة من لوجو الشعبة ولوجو الجامعة.
- الدومين، وروابط السوشال، ورابط فورم الانضمام.
- بيانات باقي الأعضاء.
